# Clínica Vitta Saúde

Experiência digital responsiva para uma clínica multidisciplinar fictícia, com comunicação humanizada e agendamento guiado.

## Demonstração

[Acessar projeto na Vercel](https://clinica-vitta-saude.vercel.app/)

## Funcionalidades

- Apresentação de especialidades e diferenciais
- Seleção de especialidade, dia e horário
- Resumo e confirmação pelo WhatsApp
- Estados interativos e mensagens de segurança
- Layout responsivo, acessível e otimizado para SEO

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Executar localmente

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

## Aviso

Projeto demonstrativo. Clínica, profissionais, horários e contatos são fictícios. O site não oferece orientação médica.
